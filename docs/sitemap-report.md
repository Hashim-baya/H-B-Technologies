- **Admin:** Protected by authentication and robots.txt disallow
- **APIs:** Not content, crawler error sources
- **External Blog:** Canonical points to external site; we link but don't claim ownership
- **404/OG:** Not indexable content

## Sitemap Structure & Metadata

### Root Element
```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"
        xmlns:image="http://www.google.com/schemas/sitemap-image/1.1"
        xmlns:video="http://www.google.com/schemas/sitemap-video/1.1">
```

### Entry Elements

Each `<url>` entry includes:

1. **`<loc>`** (required)
   - Example: `https://www.vizia.co.ke/services/web-development`
   - Uses production domain from `src/lib/site.ts` (PRODUCTION_SITE_URL)
   - Fallback chain: `VIZIA_DOMAIN_NAME` → `VERCEL_URL` → production hardcoded

2. **`<lastmod>`** (required)
   - Static pages: Current build timestamp (now())
   - Blog posts: Article creation date from Supabase (created_at)
   - Format: ISO 8601 (YYYY-MM-DDTHH:mm:ssZ)

3. **`<changefreq>`** (optional, advisory)
   - `weekly` – Homepage (can feature new services/testimonials)
   - `monthly` – Services & blog (content-driven updates)
   - `yearly` – Contact, book-consultation forms (rarely change)
   - Note: Crawlers may ignore; revalidation intervals are actual controls

4. **`<priority>`** (optional, relative)
   - `1.0` – Homepage (ultimate entry point)
   - `0.8` – Services (core business pages)
   - `0.6-0.7` – Blog, static forms (supporting content)
   - Note: Crawlers use as advisory; content quality matters more

5. **`<image:image>`** (optional)
   - URL to social preview image for the page
   - Example: `https://www.vizia.co.ke/og?type=service&slug=web-development`
   - Generated by `/og` route (Open Graph images)
   - Improves SERP appearance and social sharing

6. **`<video:video>`** (optional, homepage only)
   - URL: Hero video MP4 (`/videos/hero-video.mp4`)
   - Player URL: Homepage (`/`)
   - Title: "VIZIA Technologies - Secure by Design"
   - Description: Value proposition
   - Thumbnail: OG image
   - Duration: 15 seconds
   - Upload Date: 2025-01-01 (approximate brand video launch)
   - Metadata helps Google showcase video in search results

The `robots.txt` file correctly references the sitemap:

```
User-agent: *
Allow: /
Disallow: /api/
Disallow: /admin/

Sitemap: https://www.vizia.co.ke/sitemap.xml
Host: https://www.vizia.co.ke
```

**Key Points:**
- Sitemap URL uses production domain (with-www consolidation)
- Host header tells Google to use www version for canonicalization
- Crawl rules allow homepage, services, blog; block admin and API

## Implementation Details

### Source Files

**[src/app/sitemap.ts](../hb-technologies/src/app/sitemap.ts)** (MetadataRoute)
- Generates dynamic XML sitemap for Next.js App Router
- Fetches services from `src/content/services.ts`
- Fetches blog posts from Supabase API with fallback
- Assembles sitemap entries with proper priorities and metadata
- Returns type-safe `MetadataRoute.Sitemap` array

**[src/app/robots.txt](../hb-technologies/src/app/robots.txt.ts)** (MetadataRoute)
- Generates crawl rules for all user agents
- References sitemap URL
- Sets Host header for www preference
- Returns type-safe `MetadataRoute.Robots` object

**[src/lib/site.ts](../hb-technologies/src/lib/site.ts)** (Utility)
- `PRODUCTION_SITE_URL = "https://www.vizia.co.ke"`
- `getSiteUrl()` – resolves domain from env vars with fallback
- Used by sitemap and robots to ensure consistent production URLs

### Build Process

```

├─ Compiles TypeScript
├─ Type-checks MetadataRoute signatures
├─ Generates static routes (1 homepage, 6 static pages, 12 services, 8+ blog posts)
├─ Outputs: 25 prerendered HTML pages + 2 MetadataRoute responses
└─ Routes tagged with revalidation intervals for cache control
```

## SEO Impact & Search Engine Crawling

### Benefits

1. **Automatic Discovery** – Eliminates need for manual URL submission
2. **Priority Signaling** – Homepage (1.0) > Services (0.8) > Blog (0.6) guides crawl allocation
3. **Change Frequency** – Hints at content freshness; may affect crawl scheduling
4. **Image Metadata** – Helps Google index social preview images for rich snippets
5. **Video Metadata** – Homepage video eligible for video SERP placement
6. **Authority Distribution** – Sitemap structure reflects information hierarchy

### Crawl Efficiency

- **Googlebot** discovers homepage → follows links → checks robots.txt → fetches sitemap → prioritizes based on `<priority>` values
- **Expected crawl pattern:** Homepage (1.0) → Services (0.8) → Blog (0.6) → Forms (0.7)
- **Revalidation:** Static routes revalidate every 30s; actual content changes less frequently (ISR backoff)
